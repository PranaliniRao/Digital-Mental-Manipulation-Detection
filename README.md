# Psychological Vulnerability Modeling for Digital Manipulation Detection

This is a Streamlit-based research prototype designed to detect digital manipulation (such as phishing, scams, emotional blackmail, and social engineering) by modeling sequential psychological factors rather than classifying text directly.

Instead of predicting "manipulative or not" in a single step, this pipeline models the cognitive and emotional mechanics of influence:
`Input Text` → `Intent Analyzer` → `Vulnerability Analyzer` → `Influence Strategy Analyzer` → `Judge Agent` → `Final Manipulation Assessment`
